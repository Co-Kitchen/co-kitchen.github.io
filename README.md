# Co-Kitchen — web pública

Sitio de GitHub Pages de Co-Kitchen, servido en `https://co-kitchen.github.io/`.

- `/join/` — página de invitación. La app comparte `…/join/?code=XXXXXXXX`; la
  página enseña el código y ofrece abrir la app (`appcocina://join?code=…`).
  Existe porque WhatsApp y compañía **no** convierten en enlace pulsable un
  esquema propio: solo `http(s)://`.
- `/privacy/` — Política de Privacidad (obligatoria para la ficha de Play).
- `/terms/` — Términos y Condiciones.

Sustituye al repo `Diegocharro/app-cocina-legal`, que se queda solo
redirigiendo aquí para no romper los enlaces ya repartidos ni los que constan
en la ficha de la tienda.
